## What this table shows

Read the PERIODIC_BALANCED row across. The most common value estimate rates
it above every other fixture, including the genuinely random control, because
its histogram is exactly uniform while a real random draw carries sampling
noise. The sequence is `0,1,2,3,4,5` repeating: the next symbol is certain.
The sequential estimators report it at effectively zero.

That single row is the argument for the whole tool. A process can be perfect
under the check most people apply and worthless in fact.

STICKY_MARKOV makes the same point in a form closer to a real defect. Its
histogram is within sampling noise of the fair control, so frequency analysis
sees almost nothing, while the lag predictor identifies lag 1 as the winning
lag: the die is repeating its previous face.

BIASED is the control for the opposite direction. The defect is in the
histogram alone, the frequency estimator is limiting, and the lag predictor
understates it. Neither family dominates, which is why the pipeline reports
the minimum across all of them.

LOW_SAMPLE uses the same generator as FAIR_LIKE with 40 observations instead
of 6000. The sequential estimators decline rather than return a number. The
correct response to too little data is to say so.
